# 教學簡報

`vibe-coding-workshop.pptx` — 三小時課程用的完整簡報，35 頁。

## 結構

| 段落 | 頁數 | 內容 |
|---|---|---|
| 開場 | 1–4 | 課程地圖、期待管理、時間分配 |
| 第一段 | 5–11 | 資訊網站：怎麼把需求講清楚給 AI |
| 第二段 | 12–18 | 加上圖片：檔案怎麼跟網頁連結 |
| 第三段 | 19–25 | 靜態儀表板：資料怎麼變成畫面 |
| 第四段 | 26–32 | 可互動儀表板：邊界在哪 |
| 收尾 | 33–35 | 回顧、應用場景 |

四張「成品」頁用的是 `demos/` 裡的實際截圖，不是示意圖。

## 講者備忘

每一頁都寫了講者備忘稿（PowerPoint 下方的備忘欄），包含帶課的節奏建議、
哪裡該停、哪裡容易卡住。放映前可以先看一遍。

## 版面

紙本講義的排版邏輯：暖白紙底、單欄為主、標題下壓一條通欄細線、
段落之間靠留白與細線分隔，不使用卡片方框。等寬字只出現在真的是程式碼的地方
（資料夾樹狀圖、`<img src="...">` 拆解），其餘一律中文字體。

## 配色與段落

- 第一段、第二段（建案網站）用赭褐色
- 第三段、第四段（儀表板）用墨藍色
- 深色頁只用在封面、段落分隔、結尾

顏色本身就在告訴學員「現在走到課程的哪一段」。色票與 `demos/` 的紙本色系一致。

## 重新產生

簡報是用程式生成的，來源在 `src/`：

```bash
cd src && npm install && npm run build
```

`pptxgenjs` 的版本鎖在 `package.json`（4.0.1），不要改成 `^` 開頭——
這個檔案是一次性生成工具，跟著上游升版只會有風險沒有好處。

`npm run build` 會產生 pptx 並自動搬到 `slides/`。若直接跑 `node build.js`，
檔案會留在 `src/` 底下，要自己搬。

`src/p1–p4.jpg` 是四張成品截圖：

| 檔案 | 內容 |
|---|---|
| `p1.jpg` | 建案網站的「五分鐘」段落（純文字排版，畫面上沒有照片） |
| `p2.jpg` | 建案網站首屏（有照片） |
| `p3.jpg` | 儀表板靜態版 `?stage=3` |
| `p4.jpg` | 儀表板可上傳版，捲到「換一份資料」 |

若 `demos/` 的網頁改版，需要重新截圖替換。版面上是 7.35 × 7.5 吋，
截圖請用接近 1:1 的直幅視窗（例如 1470 × 1500）。
