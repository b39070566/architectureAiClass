# 教學簡報

`vibe-coding-workshop.pptx` — 三小時課程用的完整簡報，35 頁。

## 結構

| 段落 | 頁數 | 內容 |
|---|---|---|
| 開場 | 1–4 | 課程地圖、期待管理、時間分配 |
| Stage 01 | 5–11 | 資訊網站：怎麼把需求講清楚給 AI |
| Stage 02 | 12–18 | 加上圖片：檔案怎麼跟網頁連結 |
| Stage 03 | 19–25 | 靜態儀表板：資料怎麼變成畫面 |
| Stage 04 | 26–32 | 可互動儀表板：邊界在哪 |
| 收尾 | 33–35 | 回顧、應用場景 |

四張「成品」頁用的是 `demos/` 裡各階段網頁的實際截圖，不是示意圖。

## 講者備忘

每一頁都寫了講者備忘稿（PowerPoint 下方的備忘欄），包含帶課的節奏建議、
哪裡該停、哪裡容易卡住。放映前可以先看一遍。

## 配色與段落

- Stage 01–02（建案網站）用黃銅色
- Stage 03–04（儀表板）用藍圖藍
- 深色頁只用在封面、段落分隔、結尾

顏色本身就在告訴學員「現在走到課程的哪一段」。

## 重新產生

簡報是用程式生成的，來源在 `src/`：

```bash
cd src && npm install pptxgenjs && node build.js
```

`src/p1–p4.jpg` 是四張成品截圖，若 `demos/` 的網頁改版，需要重新截圖替換。
