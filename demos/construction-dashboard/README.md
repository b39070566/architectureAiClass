# 建案進度監控儀表板（示範）

純 HTML／JavaScript 的靜態儀表板示範，用於「vibe coding」課程教材。

## 怎麼用

直接用瀏覽器打開 `index.html`，預設會顯示 7 個示範案場的資料。
也可以點「上傳 CSV」，選 `sample.csv`（或自己準備的同格式檔案），畫面會立刻重新渲染。

## 重點觀念（課堂講解用）

- **做得到**：選檔案上傳 CSV，瀏覽器端 JavaScript 讀取並即時畫出圖表，完全不需要伺服器。
- **做不到**：資料不會被儲存，重新整理頁面就會回到示範資料；也不會跨裝置、跨使用者同步——因為沒有連接任何資料庫或後端服務。
- 適合「週報／月報」這種定期產出快照的場景，不適合需要多人即時協作更新的場景。

## CSV 欄位格式

| 欄位 | 說明 |
|---|---|
| 案名 | 建案名稱 |
| 階段 | 目前施工階段 |
| 完成率 | 0–100 的整數 |
| 已售戶數 | 整數 |
| 總戶數 | 整數 |
| 狀態 | 正常 / 落後 / 即將完工 |
