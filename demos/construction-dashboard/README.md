# 建案進度監控儀表板（示範）

純 HTML／JavaScript 的靜態儀表板示範，用於「vibe coding」課程教材。

## 怎麼用

直接用瀏覽器打開 `index.html`，預設會顯示 7 個示範案場的資料（內建在網頁裡，不用另外開檔）。
也可以點「上傳 CSV」，選 `sample.csv`——這是刻意準備的**測試資料集**，20 個案場、跟預設畫面上的示範資料完全不同名字，用來驗證「換一份資料上傳，畫面真的會跟著換」。
上課時也可以直接讓學員自己準備一份同格式的CSV上傳。

## 重點觀念（課堂講解用）

- **做得到**：選檔案上傳 CSV，瀏覽器端 JavaScript 讀取並即時畫出圖表，完全不需要伺服器。
- **做不到**：資料不會被儲存，重新整理頁面就會回到示範資料；也不會跨裝置、跨使用者同步——因為沒有連接任何資料庫或後端服務。
- 適合「週報／月報」這種定期產出快照的場景，不適合需要多人即時協作更新的場景。

## 編碼注意事項（Windows 使用者必看）

Excel 在 Windows 上另存 CSV 時，預設選項是「CSV (逗號分隔)」，存出來的檔案是 **Big5** 編碼，瀏覽器讀取會整篇變亂碼。

存檔時請選 **「CSV UTF-8 (逗號分隔)」**，才能正常顯示中文。

網頁本身也有做保護：上傳時會自動偵測編碼（UTF-8 讀不出中文就改用 Big5 試一次），並且在欄位對不上、資料是空的、或數字欄位格式不對時，畫面上會顯示紅色錯誤提示，說明問題出在哪裡，而不是直接空白。

## CSV 欄位格式

| 欄位 | 說明 |
|---|---|
| 案名 | 建案名稱 |
| 階段 | 目前施工階段 |
| 完成率 | 0–100 的整數 |
| 已售戶數 | 整數 |
| 總戶數 | 整數 |
| 狀態 | 正常 / 落後 / 即將完工 |
