# Stage 03 · 靜態儀表板

把 Excel 進度表變成資料視覺化網頁的第一版——數字**直接寫死在
`index.html` 裡**，沒有上傳功能。`source-data.csv` 是這份網頁背後
對應的原始資料，純粹讓學員理解「表格 → 網頁上的KPI／進度條／表格」
這個對應關係是怎麼發生的。

## 這階段教什麼

第一次處理「有欄位結構的資料」：認識案名、階段、完成率、已售戶數、
總戶數、狀態這些欄位，怎麼變成KPI卡片、進度條、狀態標籤。

## 跟 Stage 04 的差異（刻意設計成對照組）

這一版每次要更新資料，都要請AI「把表格換成新的一批數字」重新生成
一次網頁——這正是 Stage 04 要解決的事：讓網頁自己讀取上傳的CSV檔案，
不用每次重新生成整份網頁。

上課時建議把 Stage 03 和 Stage 04 並排展示，讓學員直接感受兩者差在哪。

## 檔案

- `index.html` — 儀表板本體（資料寫死）
- `source-data.csv` — 對應的原始資料（帶 UTF-8 BOM，Windows Excel可直接開）
