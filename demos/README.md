# vibe coding 課程教材 · 四階段、兩份檔案

建商員工班（非資訊背景，3 小時課程）的教材範例。四個階段共用同一個虛構建案
「沐森」當貫穿主題，每階段只疊加一個新概念，學員不用每階段重新理解情境。

## 資料夾結構

| 資料夾 | 對應階段 | 說明 |
|---|---|---|
| `00-curriculum-overview/` | 總覽 | 四階段架構一頁式總覽，給老師用的課程地圖 |
| `01-info-website/` | Stage 01 + 02 | 建案介紹單頁網站，含 `images/` 資料夾 |
| `02-progress-dashboard/` | Stage 03 + 04 | 進度儀表板，支援上傳 CSV 即時重繪 |

## 為什麼四個階段只有兩份檔案

因為 Stage 02 本來就是 Stage 01 加上圖片，Stage 04 本來就是 Stage 03 加上上傳功能——
兩組各自是同一份東西的前後兩個狀態，不是兩份獨立教材。分成四個資料夾只會讓學員
對著兩份幾乎一樣的檔案發呆，也讓內容要改兩遍。

前一階段的狀態這樣帶：

- **Stage 01**：直接看 `01-info-website/`，先只講文字排版的部分，不提圖片。
- **Stage 03**：開 `02-progress-dashboard/index.html?stage=3`，
  這個參數會把「換一份資料」整段收起來，頁面就是一份資料寫死的靜態儀表板。
  講完「要更新就得重做整頁」這個痛點，再拿掉參數重新整理，上傳功能就出現了。

痛點和解法在同一個畫面上先後出現，比開兩個分頁對照更有感。

## 怎麼用

兩個資料夾都是可以直接用瀏覽器打開的獨立網頁（`index.html`），彼此不互相依賴，
不需要網路、不需要安裝任何東西。

`02-progress-dashboard/` 裡有兩份 CSV：

- `built-in-data.csv` — 網頁裡內建那份示範資料的表格版，用來講「表格 → 畫面」的對應關係
- `upload-sample.csv` — 20 個案場、名字跟內建資料完全不同，用來驗證「換一份資料上傳，畫面真的會換」

兩份都帶 UTF-8 BOM，Windows Excel 可以直接雙擊打開不亂碼。

## 課程邏輯

1. **Stage 01 → 02**：從「純文字網站」到「有自己的照片」。學員弄懂
   `src="images/hero.jpg"` 在講什麼，就能把照片放進資料夾自己換圖，第一次產生擁有感。
2. **Stage 02 → 03**：從「內容網站」換軌到「資料工具」。這是全課最大的一次跨越——
   任務性質、思考方式與視覺語言全部改變，時間要留得比看起來更多。
3. **Stage 03 → 04**：從「靜態快照」到「可互動」。這一步順勢帶出資料庫／API 的邊界
   在哪裡，當作未來延伸的鉤子，不用在 3 小時內真的教。

Stage 02 和 Stage 04 都在處理「網頁怎麼取得外部檔案」，但方向相反，剛好互補：
Stage 02 是**檔案放在資料夾裡、網頁去讀它**（改檔案就好，不用改網頁）；
Stage 04 是**使用者當場上傳檔案、網頁即時運算**（不會存下來，重新整理就沒了）。
兩邊都體會過，Stage 04 最後講「為什麼想要即時同步就得接資料庫」時會好懂很多。
