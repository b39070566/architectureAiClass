# Stage 01 · 資訊網站

「沐森 MUSEN」建案介紹單頁網站。純文字排版，沒有任何圖片。

## 檔案

```
01-info-website/
└── index.html
```

一個檔案就是全部，用瀏覽器直接打開即可。

## 設定

台中七期經貿園區的高端住宅，客群為中高階城市菁英，
主打「步行五分鐘抵達台中市政府捷運站」與森林中庭。

## 頁面內容

首屏、生活尺度（五分鐘主打）、建築理念、規劃特色、格局配置、聯絡資訊。

建案名稱、地址、規格與聯絡資訊均為虛構。

## 關於視覺

刻意只做暗場單一主題，不提供亮色版本——高端建案文宣的視覺世界就是夜色，
做亮色版會稀釋掉私宅感。這是設計選擇，不是遺漏，值得在課堂上提一句。

## 跟 Stage 02 的關係

Stage 02 是同一份網站加上圖片（首圖底圖與空間圖輯）。
兩個並排打開，就能看出「加了圖片」實際上改變了什麼。
