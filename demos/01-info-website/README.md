# Stage 01 · 資訊網站

「翠湖苑」建案介紹單頁網站，示範第一次跟AI要求生成網頁的成果。

## 這階段教什麼

不是教code，是教「怎麼把需求講清楚給AI」（prompt結構）：講清楚
建案名稱、要有哪些區塊（特色/格局/生活機能/聯絡資訊）、想要的調性
（溫暖、質感），AI就能一次生成一份看起來完整的網站。

## 內容

純靜態單頁，沒有互動功能：
- Hero區（用CSS格線畫出建築立面示意，沒有真實圖片）
- 建案特色（3張卡片）
- 格局配置表
- 生活機能清單
- 聯絡資訊

## 課堂上可以怎麼帶

打開這頁，直接請學員唸出「如果是你的建案，你會怎麼描述？」，然後現場
示範把描述丟給AI、生成類似結構的網頁。內容是虛構的，重點在**結構**，
不是這個特定建案的文案。
