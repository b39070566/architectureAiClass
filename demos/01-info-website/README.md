# Stage 01 · 資訊網站

「翠湖苑」建案介紹單頁網站，示範第一次跟AI要求生成網頁能做到什麼程度。

## 這階段教什麼

不是教 code，是教「怎麼把需求講清楚給AI」：講清楚建案名稱、要有哪些區塊、
想要的調性（沉靜、有質感、像建築師事務所的作品集而不是廣告傳單），
AI 就能一次生成一份結構完整的網站。

## 內容

純靜態單頁，沒有任何互動功能：

- 首圖（湖景）＋直排標語
- 建案理念
- 建案特色（三項）
- 格局配置表
- 環境圖輯（三張）
- 生活機能（點線索引式）
- 聯絡資訊

## 圖片說明

頁面上的湖景不是外部圖檔，是用 Canvas 程式即時繪製的——山稜、水面倒影、
霧帶、蘆葦都是算出來的。這樣整份網頁只要一個 `index.html` 就能運作，
不用處理圖片路徑，複製給學員也不會缺檔。

深色模式會自動換成傍晚色調，不是把亮色反轉。

## 課堂上可以怎麼帶

打開這頁，請學員說說「如果是你的建案，你會怎麼描述？」，然後現場示範
把這段描述丟給AI、生成類似結構的網頁。內容是虛構的，重點在**結構與敘述方式**，
不是這個特定建案的文案。

下一步（Stage 02）會讓學員把這些圖換成自己的照片。
