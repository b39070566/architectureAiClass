# Stage 01 · 資訊網站

「翠湖苑」建案介紹單頁網站，示範第一次跟AI要求生成網頁能做到什麼程度。

## 這階段教什麼

不是教 code，是教「怎麼把需求講清楚給AI」：講清楚建案名稱、要有哪些區塊、
想要的調性（沉靜、有質感，像建築師事務所的作品集而不是廣告傳單），
AI 就能一次生成一份結構完整的網站。

## 檔案結構

```
01-info-website/
├── index.html            ← 網頁本身
└── images/               ← 圖片資料夾
    ├── hero.jpg          ← 首圖（外觀）
    ├── interior-1.jpg    ← 客廳
    ├── interior-2.jpg    ← 主臥
    └── interior-3.jpg    ← 大廳
```

網頁和圖片是**分開的兩件事**——這個結構本身就是 Stage 02 要教的內容，
這裡先讓學員看過一次就好，不用細講。

## 頁面內容

純靜態單頁，沒有任何互動功能：

- 首圖（外觀）＋建案名
- 建案理念（含直排標語）
- 建案特色（三項）
- 格局配置表
- 內裝圖輯（客廳／主臥／大廳）
- 生活機能（點線索引式）
- 聯絡資訊

## 圖片說明

`images` 裡的圖是示意圖，不是實景照片。Stage 02 會讓學員換成自己的照片。

## 課堂上可以怎麼帶

打開這頁，請學員說說「如果是你的建案，你會怎麼描述？」，然後現場示範
把這段描述丟給AI、生成類似結構的網頁。內容是虛構的，重點在**結構與敘述方式**，
不是這個特定建案的文案。
