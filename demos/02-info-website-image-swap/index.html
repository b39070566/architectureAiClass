Stage 02 · 課堂說明

把你自己的照片放上這個網站

網頁本身不會把圖片存在裡面。它只記住一件事：這張圖放在哪個資料夾、叫什麼名字。 所以換照片不用改網頁——把檔案換掉就好。

一、先看資料夾長什麼樣

02-info-website-image-swap/
├── index.html            ← 網頁本身
└── images/               ← 圖片資料夾
    ├── hero.jpg          ← 首圖
    ├── interior-1.jpg    ← 客廳
    ├── interior-2.jpg    ← 主臥
    └── interior-3.jpg    ← 大廳

網頁上每張圖的左下角都標了它對應的檔名，可以邊看畫面邊對照這棵樹。

二、網頁裡是這樣寫的

<img src="images/hero.jpg" />

src 的意思就是「這張圖在哪裡」。
images/hero.jpg 讀作：跟 index.html 放在同一層的 images 資料夾裡，有個叫 hero.jpg 的檔案。

所以只要那個位置有一個叫這個名字的圖檔，網頁就會把它顯示出來—— 至於那張圖是湖景還是你昨天在工地拍的，網頁不在意。

三、換成自己的照片，兩種做法

  1. 做法一：改檔名（最簡單，不用碰程式碼）
    把你的照片改名成 hero.jpg，複製進 images 資料夾蓋掉原本那張， 回到瀏覽器按重新整理，首圖就換好了。其他三張同理。
  2. 做法二：改網頁裡的檔名（照片多的時候比較方便）
    把照片直接放進 images 資料夾不改名，例如 工地實景.jpg， 然後把 index.html 裡的 src="images/hero.jpg" 改成 src="images/工地實景.jpg"。
  3. 不會改程式碼？把需求講給 AI 聽就好
    「我把照片放進 images 資料夾了，檔名是 工地實景.jpg，請幫我把首圖換成這張」—— 這樣描述，AI 就能告訴你要改哪一行。這也是這門課一直在練的事： 講清楚你要什麼，比自己寫程式重要。

四、圖片破掉的話，先檢查這三件事

  • 檔名有沒有完全一樣？ Hero.jpg 和 hero.jpg 在某些情況下算不同的檔案，大小寫要對。
  • 副檔名對不對？ 手機拍的照片有時是 .jpeg 或 .HEIC，不是 .jpg。 副檔名不同就要改網頁裡的 src，或把檔案轉存成 jpg。
  • 檔案真的放進 images 資料夾了嗎？ 放在外面、或多包了一層資料夾都會找不到。這頁做了提示：如果圖片載入失敗， 畫面上會直接寫出它在找哪個路徑。
