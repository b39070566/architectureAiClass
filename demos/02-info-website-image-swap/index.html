Concept

把湖光留在客廳，把山線留在陽台。
建築退後，讓風景先進來。

基地南側正對翠湖，我們把主要開窗面全數轉向水岸，並將棟距拉開至 32 公尺，確保每一戶都能保有完整的湖面視野。低層規劃讓建築量體伏貼於環湖綠帶的天際線，不與環境爭高。

Features

建案特色

基地座向

南向面湖，北側退縮設置停車動線，主要生活空間全數避開西曬，夏季室溫可有效降低。

建材規格

外牆採清水模一次性澆置，對外窗使用低輻射複層玻璃，隔音與隔熱同步處理。

公共空間

一樓大廳挑高六米並向湖面開放，屋頂設置空中花園與健身房，公設比控制於 28%。
