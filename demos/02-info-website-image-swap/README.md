# Stage 02 · 加上自己的圖片

跟 Stage 01 是同一份網站，多了圖片：首圖，以及新增的「內裝圖輯」區塊。

## 檔案

```
02-info-website-image-swap/
├── index.html
└── images/
    ├── hero.jpg          首圖
    ├── interior-1.jpg    客廳
    ├── interior-2.jpg    主臥
    └── interior-3.jpg    大廳
```

`images` 裡的四張是示意圖，供學員替換成自己的照片。

## 頁面內容

與 Stage 01 相同，另加首圖與內裝圖輯。
建案名稱、地址、聯絡資訊均為虛構，圖片為示意圖。
