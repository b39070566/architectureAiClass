# Stage 02 · 換成自己的圖片

跟 Stage 01 是**同一份網站**，只多了一件事：每張圖右下角都有「更換圖片」按鈕，
可以換成學員自己拍的照片。除此之外，文字、版面、格局表、配色完全相同。

## 這階段教什麼

讓學員把「別人做的範例」變成「我自己的東西」——換上自己部門的建案照片、
自己拍的工地實景，網站立刻變成有切身感的作品。這是四階段裡第一次
產生「擁有感」的地方。

技術上也埋了一個跟 Stage 04 一致的觀念：**檔案只留在瀏覽器裡**，
重新整理頁面就會恢復原狀。Stage 02 換的是圖片，Stage 04 換的是資料，
但「靜態快照、不會儲存」的邊界是同一個。

## 可以換的位置（共 4 張）

| 位置 | 說明 |
|---|---|
| 首圖 | 頁面最上方的大圖 |
| 環境圖輯 × 3 | 湖畔晨景、環湖綠帶、遠山稜線 |

上方深色教學條會即時顯示「已更換 N / 4 張」，也可以一鍵「還原全部圖片」。

## 幾個實作細節（值得在課堂上提一下）

- **換上自己的照片後，首圖會自動切換成深色遮罩＋白色標題**。因為學員上傳的
  照片可能很亮也可能很暗，固定用深色字會在淺色照片上看不見——這是「做東西
  要考慮真實使用情況」的好例子。
- 選到非圖片檔會顯示紅色提示，不會默默失敗。
- 預設圖是用程式即時繪製的（Canvas），不是外部圖檔，所以整份網頁單一檔案
  就能運作，不用管圖片路徑。

## 課堂上可以怎麼帶

Stage 01 和這頁各開一個分頁對照。先讓學員看 Stage 01「這是AI生成的範例」，
再切到這頁請他們拿手機照片實際換上去——「同一份網站，現在是你的了」。
