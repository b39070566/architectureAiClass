# Stage 02 · 資訊網站・改圖片

跟 Stage 01 是同一份網站，只請AI做了一個修改：「把首圖立面改成清水模
建材、天空改成夕陽色調」，其餘文字、版面、格局表完全沒動。

## 這階段教什麼

理解生成結果不是一次性的定稿，而是**可以持續對話迭代**的——不用整頁
重寫，只要精準描述「哪裡要換、換成什麼」，AI就能只動那一塊。

## 跟 Stage 01 的差異

打開頁面最上方有一條虛線框的教學註記，直接寫出這次改了什麼指令
（`「把首圖立面改成清水模建材、天空改成夕陽色調」`）。這條註記只是給
課堂看的，不是網站本身的內容，實際網站部分（topbar以下）才是成果。

## 課堂上可以怎麼帶

建議把 Stage 01 和這頁並排開兩個分頁，讓學員實際切換對照「同一份網站，
換了什麼」，比純口頭講解「AI可以修改」更有說服力。
