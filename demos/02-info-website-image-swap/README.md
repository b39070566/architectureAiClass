# Stage 02 · 加上自己的圖片

跟 Stage 01 是同一份網站，多了圖片：首屏底圖，以及新增的「空間圖輯」區塊。

## 檔案

```
02-info-website-image-swap/
├── index.html
└── images/
    ├── hero.jpg      首屏底圖（森林）
    ├── space-1.jpg   起居
    ├── space-2.jpg   主臥
    └── space-3.jpg   中庭
```

`images` 裡的四張是示意圖，供學員替換成自己的照片。

## 頁面內容

與 Stage 01 相同，另加首屏底圖與空間圖輯。
建案名稱、地址、規格與聯絡資訊均為虛構，圖片為示意圖。
