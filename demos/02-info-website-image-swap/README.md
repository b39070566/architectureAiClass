# Stage 02 · 換上自己的照片

跟 Stage 01 是**同一份網站、同一批圖片**，差別只有一個：這頁多了一段課堂說明，
教學員「資料夾裡的圖片檔，怎麼跟網頁連起來」。

## 這階段教什麼

一句話：**網頁不會把圖片存在裡面，它只記住「圖片放在哪裡、叫什麼名字」。**

```
02-info-website-image-swap/
├── index.html            ← 網頁本身
└── images/               ← 圖片資料夾
    ├── hero.jpg          ← 首圖
    ├── interior-1.jpg    ← 客廳
    ├── interior-2.jpg    ← 主臥
    └── interior-3.jpg    ← 大廳
```

網頁裡寫的是：

```html
<img src="images/hero.jpg" />
```

`src` 就是「這張圖在哪裡」。`images/hero.jpg` 讀作：跟 `index.html` 放在同一層的
`images` 資料夾裡，有個叫 `hero.jpg` 的檔案。

搞懂這一句，學員就能自己換圖，不用等人幫忙。

## 頁面上做了哪些教學輔助

- **每張圖左下角標出它的檔名**，可以邊看畫面邊對照 `images` 資料夾，
  不用猜「這張是哪個檔」。
- **圖片載入失敗時，畫面會直接寫出它在找哪個路徑**。學員檔名打錯（例如
  大小寫不對、副檔名是 `.jpeg` 不是 `.jpg`）時，錯誤訊息本身就是提示。
- 頁面中段有完整的課堂說明區，包含資料夾結構、`src` 的意思、兩種換圖做法、
  以及破圖時的三個檢查點。

## 換圖的兩種做法（課堂上兩種都要示範）

1. **改檔名**：把照片改名成 `hero.jpg`，蓋掉 `images` 裡原本那張，重新整理網頁。
   最簡單，完全不用碰程式碼。
2. **改網頁裡的檔名**：照片直接放進 `images` 不改名，然後把 `index.html` 裡的
   `src="images/hero.jpg"` 改成自己的檔名。照片多的時候比較好管理。

第三種其實才是這門課的重點：**不會改就把需求講給 AI 聽**——
「我把照片放進 images 資料夾了，檔名是 工地實景.jpg，請幫我把首圖換成這張」。

## 課堂上可以怎麼帶

1. 先開 Stage 01，說「這是 AI 生成的網站」
2. 切到這頁，捲到「課堂說明」區，一起看資料夾結構跟 `src` 那一行
3. 請學員拿自己的照片，用做法一實際換一次首圖
4. 故意把檔名打錯一次，讓他們看到破圖提示——理解「電腦是照字面找檔案的」

## 為什麼首圖固定用深色遮罩

學員換上的照片可能很亮也可能很暗，如果標題用固定顏色，遇到淺色照片就會看不見。
所以首圖一律套深色漸層＋白色標題——這是「做東西要考慮真實使用情況」的現成例子，
值得在課堂上提一句。
